# 项目器材焊接清单

更新时间：2026-09-03

本文记录当前项目中哪些器材需要焊接，以及焊接的先后条件。最终 STM32 引脚、定时器、DMA、电平和 PPR 未确认前，不得提前焊接未知信号线。

## 已完成

- [x] WeAct STM32G431 核心板两侧 I/O 排针已安装。
- [x] 核心板中央 `DIO / CLK / GND` SWD 排针已焊接；Issue #48 已完成三线复核、两次只读目标识别和断开后的原点灯固件恢复验证。
- [x] 核心板侧边 `PA9` 和 `GND` 可用于单向 UART 验证。
- [x] `PA9 -> CH340 RXD`、`GND -> GND` 当前可用跳线连接，不要求立即焊死。

## SWD 已验证接线

中央 `DIO / CLK / GND` 排针已经焊接，Issue #48 已按以下三线完成只读调试链路验证。每次重新接线仍须在断电状态按丝印复核：

```text
ST-LINK SWDIO  -> 核心板 DIO（PA13）
ST-LINK SWCLK  -> 核心板 CLK（PA14）
ST-LINK GND    -> 核心板 GND
```

- ST-LINK 的 `3V3`、`5V`、`RST`、`SWIM` 不接。
- 核心板继续由 USB-C 单独供电。
- SWD 排针不是继续 UART/RPM 开发的必需条件，USB DFU 已可用。

## 后续必须可靠连接或焊接

### A3144E 霍尔传感器

- 传感器电源、地和输出线。
- 输出线接入后级上拉、滤波和整形电路。
- 最终安装时应使用焊接导线、插座或可靠端子，不能依赖松动跳线。

### SN74HC14 霍尔整形电路

- 4.7 kΩ 上拉电阻。
- 1 kΩ 串联电阻。
- 1 nF 起始滤波电容。
- SN74HC14 电源、地和每片芯片附近的 100 nF 退耦电容。
- 两路整形输出到 STM32 的最终连接。

面包板阶段可以先插接；进行振动、长线或电机测试前应改为可靠焊接或 PCB/端子连接。

### HCT157 旁路电路

- PX4 PWM 输入。
- STM32 修正 PWM 输入。
- HCT157 选择信号和使能信号。
- HCT157 电源、地和退耦电容。
- 两路 ESC 信号输出。

具体选择极性、使能电平和 STM32 控制引脚必须依据数据手册和最终引脚表确认后再焊接。

### PX4、ESC 和电源线

- PWM/控制信号可使用可靠插头、端子或焊接连接。
- 电调与电池主电流线必须使用合适规格的线材和连接器。
- 主电流路径不得经过面包板、洞洞板、杜邦线或信号线。

## 暂不要焊接

- 未确认的 STM32 霍尔输入引脚。
- 未确认的 PWM 输入/输出引脚。
- 未确认的 HCT157 选择控制引脚。
- 未确认的定时器、DMA、GPIO 和电平连接。
- CH340 的 `TXD`、`5V`、`3V3`、`RTS`、`CTS` 到 STM32 的任何连接。

## 推荐顺序

1. 如需 SWD 调试，先复核中央 `DIO / CLK / GND` 三线并按 Issue #48 完成只读识别。
2. 等硬件侧确认最终引脚、电压、电平和 PPR。
3. 焊接 A3144E、HC14 和 RC 滤波电路。
4. 焊接并复核 HCT157 旁路和 PWM 信号线。
5. 最后连接电调、电机和电池主电流；带电机测试必须遵守 `docs/safety.md`。
