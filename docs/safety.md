# 安全计划

## 项目安全边界

当前系统是实验原型，不是飞行认证系统。第一阶段默认拆桨，任何带桨测试都必须单独批准并满足本文件全部条件。

## 不可违反的规则

1. 初期调试必须拆除螺旋桨。
2. 电池/电调/电机主电流不得通过面包板、洞洞板、杜邦线或 28AWG 信号线。
3. 人员不得站在桨盘平面内。
4. 接线、供电、桨方向和固定必须两人交叉复核。
5. 调参一次只改一项，保留可回退固件和旁路方案。
6. 发现异常声音、振动、烟雾、温升、脉冲丢失或不可预测输出时立即急停。

## 分级测试

| 级别 | 能量状态 | 允许内容 | 必需条件 |
|---|---|---|---|
| L0 | 无电池 | 接线、静态检查 | 万用表、图纸复核 |
| L1 | 逻辑电源 | 点灯、UART、手动霍尔 | 电机主电源断开 |
| L2 | 电调供电、拆桨 | PWM/旁路/全链路 | 刚性固定、急停可用 |
| L3 | 带桨台架 | 最终性能测试 | 防护罩、远程操作、警戒区、风险复核 |

## 上电检查表

- [ ] 测试级别和停止条件已声明
- [ ] 螺旋桨状态符合测试级别
- [ ] 电机、电调、电池和台架机械固定完成
- [ ] 极性、电压、共地、信号路径和 HCT157 默认旁路已复核
- [ ] 急停/断电装置可在不进入桨盘区域的位置操作
- [ ] 逻辑分析仪、UART 日志和测试记录已准备
- [ ] 两名成员明确“操作者”和“安全观察员”

## 带桨额外条件

- 使用刚性固定台架和可承受碎桨的防护罩。
- 远程操作，人员远离桨盘平面和潜在碎片方向。
- 先单电机、低油门、短时运行，再逐级增加。
- 不在室内人员密集区、易燃物附近或无法快速断电的位置测试。
- 对螺旋桨尺寸、旋向、额定转速和安装方向完成书面确认。

## 故障响应

- 霍尔丢失/异常：停止积分和同步修正，记录故障并旁路/安全处理。
- STM32 复位/未就绪：硬件默认选择 PX4 原始 PWM。
- 输出异常或振荡：立即降油门/断电，保存日志，不重复上电直到完成复盘。
- 机械松动或过热：断电并等待完全停转/冷却后检查。

第一版旁路不能覆盖所有 MCU 锁死或错误输出；不得把它描述为完整失效安全系统。
