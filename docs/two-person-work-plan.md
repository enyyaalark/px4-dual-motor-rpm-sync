# 两人分工与三周协作安排

周期：2026-08-31 至 2026-09-18，共 15 个工作日，周末不安排任务。

本文把 `project-plan.md` 中按日期编排的工作重新整理为两个人的执行视图。动态状态、负责人和阻塞仍以 GitHub Issues 与 Project 看板为准；本文不表示相关任务已经开始或完成。

## 角色划分

### 成员 A：硬件与安全负责人（`role:hardware`）

主责：

- 确认 PX4、接收机、ESC、电池、螺旋桨、逻辑芯片和转速计的准确型号、协议与数据手册。
- 建立电源域、电压、电平阈值、共地和接口兼容性记录。
- 搭建并验证 A3144E、SN74HC14、RC 滤波、SN74HCT157 和 ESC 信号链。
- 设计霍尔安装、线束固定、刚性台架、防护罩和独立急停方案。
- 负责逻辑分析仪、万用表和独立转速计测量，保存波形、照片和原始实验条件。
- 每次上电前检查能量等级、螺旋桨状态、主电流路径、极性和急停条件。

主要 Issues：#1、#2、#4、#5、#8、#11、#12、#21；与成员 B 共同处理 #6、#13、#15、#19、#20 和 #23。

### 成员 B：固件与数据负责人（`role:firmware`）

主责：

- 建立 STM32CubeMX/CubeIDE 最小工程，完成点灯、UART 和可重复构建。
- 实现两路霍尔输入捕获、RPM 计算、超时归零和异常值检测。
- 实现 PX4 PWM 捕获、双路 PWM 输出、最终限幅和 HCT157 旁路状态逻辑。
- 集成 `INIT`、`MONITOR_ONLY`、`SYNC_CONTROL`、`BYPASS`、`FAULT` 状态机。
- 实现固定字段 UART CSV 日志，维护主机侧校验、绘图和指标计算工具。
- 在硬件标定完成后实现死区、低速禁止、P 控制、修正限幅和抗积分饱和。
- 整理开环/闭环数据，生成对比曲线、指标和最终报告。

主要 Issues：#3、#6、#7、#9、#10、#14、#16、#18、#22；与成员 A 共同处理 #13、#15、#19、#20 和 #23。#17 PI 控制仅在 P 控制数据支持时评估。

## 关键交接与依赖

1. 成员 A 未确认型号、电压和引脚依据前，成员 B 不生成假定可用的 `.ioc`，也不写死定时器或 GPIO。
2. 成员 A 提供霍尔原始/整形波形和计时范围后，成员 B 才确定计数频率、滤波和超时参数。
3. PPR 未经独立转速计多点标定前，成员 B 不启用闭环。
4. 成员 B 先用逻辑分析仪证明 PWM 捕获、输出和限幅正确，成员 A 才连接 ESC 信号。
5. HCT157 的默认选择、上电、复位和掉电行为由两人共同复核，通过后才能做拆桨全链路测试。
6. 开环基线、低速禁止、死区、最终限幅、修正限幅和故障停止修正全部具备后，才允许启用 P 控制。
7. PI 是可选项；若 P 控制没有稳定残差证据，或出现振荡，不实现 PI。
8. 带桨测试不是必须赶进度的步骤。Q05、Q06、Q10 和 L3 条件未全部关闭时，#21 保持阻塞并取消测试。

## 两人必须共同完成的事项

- 接线、供电、电平、极性、共地和 HCT157 默认旁路的上电前复核。
- PPR 标定、M1/M2/M3 验收和所有安全关键测试的交叉复核。
- 每次实验只改变一个主要变量，并记录硬件配置、固件提交、测试条件和停止原因。
- 任一霍尔异常、电机异常、持续振荡、温升、烟雾或不可控输出时立即停止，不重复上电直到完成复盘。
- 每日结束前更新对应 Issue：当前结果、证据、未验证项、阻塞和下一步。

## 安全底线

- 初期调试必须拆除螺旋桨。
- 电池和电调主电流不得经过面包板、洞洞板、杜邦线或信号线。
- 带桨测试必须具备刚性台架、防护罩、独立急停、远程操作和两人交叉复核。
- 未确认的型号、引脚、电压、协议和 PPR 始终保持 `TBD`。
- 当前交付是三周台架实验原型，不得描述为已经具备飞行安全性。
