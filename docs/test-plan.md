# 测试计划

## 原型验收目标（尚未验证）

- 两路 RPM 连续、稳定，停止后正确归零。
- 与独立转速计相比，RPM 误差目标不超过 3%。
- 中等油门稳态同步后，转速差目标不超过 3%。
- 油门变化后 1–2 秒内重新稳定。
- 修正量初步限制在基础指令跨度约 5% 以内。
- 霍尔消失后不继续错误积分；旁路恢复 PX4 原始控制。
- 无明显持续振荡；每项测试都有 CSV、条件、提交版本和结论。

## 测试矩阵

| ID | 测试 | 级别 | 主要证据 | 通过条件 |
|---|---|---|---|---|
| T01 | STM32 点灯/UART | L1 | 串口记录 | 周期输出稳定 |
| T02 | 单路霍尔静态触发 | L1 | 逻辑波形 | 电平清晰、无异常毛刺 |
| T03 | HC14/RC 参数扫描 | L1/L2 | 输入输出波形 | 不丢有效脉冲 |
| T04 | 每转脉冲标定 | L2 | 转速计+CSV | 多转速点一致 |
| T05 | 双路 RPM 与停止归零 | L2 | CSV | 连续稳定、超时归零 |
| T06 | PX4 PWM 捕获 | L1/L2 | 逻辑分析仪 | 与基准脉宽一致 |
| T07 | STM32 PWM 输出 | L1 | 逻辑分析仪 | 频率/脉宽/限幅正确 |
| T08 | HCT157 默认旁路/复位 | L1/L2 | 波形+视频 | 未就绪时选择 PX4 |
| T09 | 拆桨全链路 | L2 | CSV+视频 | 遥控双电机且记录 RPM |
| T10 | 开环基线 | L2/L3 | 多组 CSV | 条件和差异可重复 |
| T11 | P 控制阶梯调参 | L2/L3 | 对比曲线 | 误差降低且无持续振荡 |
| T12 | 霍尔断线/异常注入 | L2 | 故障日志 | 停止修正且不积分 |
| T13 | MCU 复位旁路 | L2 | 波形+视频 | 恢复 PX4 原始控制 |

T07 的主机侧 synthetic 测试只覆盖双路请求校验、整数微秒取整、最终限幅、无效配置和非有限请求隔离。它不验证定时器频率、真实脉宽、电平、双路同步更新或复位瞬态，不能替代逻辑分析仪证据。

T08/T13 的主机侧 synthetic 测试覆盖默认/复位旁路、自检和人工请求门控、活动/锁存故障语义，以及故障时同步修正和积分归零。它不验证 HCT157 默认电阻、供电时序、切换毛刺、MCU 锁死或掉电时的真实引脚电平，不能替代波形和视频证据。

Issue #7 的目标固件已把双路 HAL 捕获快照接入 C++17 RPM 评估层。PPR、Hall 超时和最大 RPM 未由 Issue #8 标定前，目标遥测必须报告 `INVALID_CONFIG` 且有效 RPM 为 0；主机测试中的 synthetic 有效/超时/异常状态只证明软件路径，不是实机 RPM 证据。

UART CSV 的主机侧 synthetic 测试覆盖固定 11 字段、全部状态名、故障位、非有限样本拒绝和缓冲区截断隔离，并由 Python 重新解析实际 C++ 输出。它不验证 UART 发送时序、丢行、DMA 或对控制周期的影响。

## 测试记录最小字段

- 日期、执行者/复核者、Issue 和固件提交哈希。
- 硬件型号、供电、PWM 范围、是否带桨、台架条件。
- 参数表、原始 CSV 路径、处理脚本版本和图表。
- 预期、实际、通过/失败、异常和下一步。

## 停止条件

任何机械松动、过热、烟雾、不可控升速、持续振荡、旁路失败、日志与观察不一致都立即停止测试。
