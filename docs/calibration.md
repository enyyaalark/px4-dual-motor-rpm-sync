# 校准流程

## 1. 测量工具

- 独立激光转速计或等效可信参考（具体型号 `TBD`）。
- 逻辑分析仪/示波器测量霍尔周期与 PWM 脉宽。
- 万用表确认电压、极性与共地。

## 2. 每转有效脉冲数

1. 拆桨并将电机可靠固定。
2. 同时记录参考 RPM、霍尔频率和至少 10 秒原始脉冲数据。
3. 在多个稳定转速点计算 `ppr = 60 * frequency / reference_rpm`。
4. 检查各点是否接近同一整数/稳定值；异常时检查安装、磁体和毛刺。
5. 将确认结果、证据和不确定度写入硬件配置，未经复核不启用闭环。

成员 A 负责固定、供电边界、转速计与逻辑分析仪的物理操作和原始数据采集；成员 B
负责用 `tools/calibrate_ppr.py` 计算候选值并对照误差。每台电机的输入至少包含两个
不同稳定点，原始 CSV 不得改写，派生结果写入 `data/processed/`。

当前 KWS-ZS2508 只有量程 `300–200000 RPM` 和分辨率 `1 RPM` 信息，精度仍为
`TBD`。分辨率不能代替精度；在取得可追溯规格前，工具必须报告
`UNVERIFIED_REFERENCE_ACCURACY`，不得据此声称满足 3% RPM 误差目标。

## 3. 电调 PWM

- 暂按 1000–2000µs 设计，但实际最小、启动、最大和失联行为必须按电调说明书与无桨测试确定。
- 校准时先验证逻辑分析仪波形，再连接 ESC 信号；保持可立即断电。
- 记录 3.3V 控制高电平是否可靠被接受。

## 4. RPM 过滤与超时

- 从原始周期数据选择合理的中值/低通策略。
- 超时阈值必须大于最低受控 RPM 的正常脉冲周期，同时足够快地归零。
- 人为断开霍尔信号，确认 RPM 归零、故障置位、积分冻结。

## 5. 控制参数

- 先固定 `Ki = 0`，从很小的 `Kp` 和修正限幅开始。
- 每个参数点使用相同电池状态、油门点和测试时长。
- 若加入 PI，记录积分限幅、抗饱和触发和恢复过程。

所有数值在实测前均为 `TBD`，不得从其他电机项目直接复制。
